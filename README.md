# Open Notes

[Открыть Open Notes](https://opennotes.github.io/opennotes/) · [Редактор](https://opennotes.github.io/opennotes/edit.html)

`index.html` — сайт проекта. `edit.html` — редактор и стартовая страница установленного приложения.

## Запуск и установка

Разместите **всю папку проекта** на статическом хостинге с HTTPS. Для локального запуска:

```sh
npx --yes serve . -l 3000
```

Откройте `http://localhost:3000`. Подсказки по установке доступны по кнопке «Установить на Mac».

- **Chrome на Mac:** установите приложение через значок в адресной строке. Для автосохранения откройте папку и разрешите изменение файлов.
- **Safari на macOS Sonoma 14+:** откройте редактор и выберите «Файл → Добавить в Dock». Safari сохраняет изменения через скачивание.

Для загрузки приложения нужен интернет. Service worker и офлайн-кэш не используются. В Chrome последняя папка и файл доступны через «Продолжить»; браузер может снова запросить разрешение.

## HTML-элемент установки

Кнопка установки на главной сначала открывает редактор. Элемент `<install>` используется в редакторе. Manifest задаёт `start_url` редактора; установленное приложение всегда запускает `edit.html?app=1`. Сохранённая в Dock главная страница перенаправляет в редактор до отображения содержимого. Поддержка определяется через `HTMLInstallElement`. В неподдерживаемых браузерах работают вложенные кнопка `beforeinstallprompt` и ссылка на инструкцию. В установленном приложении предложение установки скрыто.

Элемент экспериментальный. Для локальной проверки включите `about://flags/#web-app-install-element` в поддерживающем Chrome или Edge. Для пользователей опубликованного сайта зарегистрируйте его HTTPS-origin в Origin Trial и добавьте полученный `origin-trial` meta-токен в **обе** страницы (или передавайте HTTP-заголовок). Токен привязан к домену; в проект не включён вымышленный или чужой токен.

## GitHub Pages

Исходники и сайт находятся в одном репозитории: `opennotes/opennotes`. Публикация из корня ветки `main` по адресу https://opennotes.github.io/opennotes/. Файл `.nojekyll` включает публикацию статических файлов без обработки Jekyll.

После изменения файлов создайте коммит и опубликуйте его:

```sh
git push origin main
```
