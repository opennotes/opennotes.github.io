# Open Notes

[Открыть Open Notes](https://opennotes.github.io/) · [Редактор](https://opennotes.github.io/edit.html)

`index.html` — сайт проекта. `edit.html` — редактор и стартовая страница установленного приложения.

## Запуск и установка

Разместите **всю папку проекта** на статическом хостинге с HTTPS. Для локального запуска:

```sh
npx --yes serve . -l 3000
```

Откройте `http://localhost:3000`. Подсказки по установке доступны по кнопке «Установить на Mac».

- **Chrome на Mac:** установите приложение через значок в адресной строке. Для автосохранения откройте папку и разрешите изменение файлов.
- **Safari на macOS Sonoma 14+:** откройте редактор и выберите «Файл → Добавить в Dock». Safari сохраняет изменения через скачивание.

После первой загрузки редактор и его зависимости кэшируются для работы без сети. Кэш нужно подготовить в самом установленном приложении при первом запуске. В Chrome последний проект и файл доступны через «Продолжить»; браузер может снова запросить разрешение.

## Обновления

После изменения HTML, `pwa.js`, manifest или assets выполните:

```sh
python3 scripts/update-cache.py
```

Затем опубликуйте все файлы, включая обновлённый `sw.js`. Новая версия активируется после закрытия всех окон приложения: открытый редактор не перезагружается автоматически. Пользовательские файлы не хранятся в кэше service worker.

## HTML-элемент установки

На обеих страницах используется `<install>` для текущего приложения с тем же manifest и `id`. Поддержка определяется через `HTMLInstallElement`. В неподдерживаемых браузерах работают вложенные кнопка `beforeinstallprompt` и ссылка на инструкцию. В установленном приложении предложение установки скрыто.

Элемент экспериментальный. Для локальной проверки включите `about://flags/#web-app-install-element` в поддерживающем Chrome или Edge. Для пользователей опубликованного сайта зарегистрируйте его HTTPS-origin в Origin Trial и добавьте полученный `origin-trial` meta-токен в **обе** страницы (или передавайте HTTP-заголовок). Токен привязан к домену; в проект не включён вымышленный или чужой токен.

## GitHub Pages

Исходники: `opennotes/opennotes`. Сайт: `opennotes/opennotes.github.io`, публикация из корня ветки `main`. Файл `.nojekyll` включает публикацию статических файлов без обработки Jekyll.

В этом checkout настроены два remote: `origin` для исходников и `pages` для сайта. После обновления офлайн-кэша и коммита публикуйте одну и ту же версию в оба репозитория:

```sh
git push origin main
git push pages main
```
