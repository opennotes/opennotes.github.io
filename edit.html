File System Access API недоступен. Откройте в Chrome, Edge или Opera по localhost / HTTPS.

Браузер не поддерживает работу с файлами

Приложение сохраняет Markdown на диск через File System Access API. Без него открытие папок и автосохранение недоступны.

  • Chrome, Edge, Opera — поддерживают
  • Нужен localhost или HTTPS
  • Safari и Firefox — API пока нет

Пример: npx serve .
